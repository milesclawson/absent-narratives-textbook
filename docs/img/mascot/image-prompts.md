> artwork. Run the prompts below through an AI image tool and replace the

I am about to ask you to generate seven different poses for a book mascot.
Please use a consistent drawing style for all seven images.

Base character (embedded in full in every prompt below): A modern flat
vector illustration of Sage the Raven, a friendly pedagogical mascot for a
high school history textbook called "Absent Narratives." Sage has deep
indigo-black feathers with a subtle indigo sheen (#283593), small round
wire-frame glasses, and a worn leather satchel slung across the chest with a
rolled scroll peeking out of the top. Sage has an attentive, warm, curious
expression — never smug or cartoonishly goofy. The character is small to
medium in size, suitable for icon-sized display up to quarter-page display.
Style: modern flat vector illustration, clean lines, transparent background
with alpha channel, suitable for embedding in educational content. No text
in image.

Generate each image as an RGBA PNG with a fully transparent alpha-channel
background. The background MUST be fully transparent — DO NOT use a white,
black, or checkered background.
