# Mascot Style Guide

This page shows all mascot admonition styles for reference. Once the seven
pose images are generated and saved to `docs/img/mascot/` (see
[image-prompts.md](../img/mascot/image-prompts.md)), each block below should
render with its corresponding pose image floated to the left of the text.

!!! mascot-neutral "General Note"
    ![Sage neutral pose](../img/mascot/neutral.png){ class="mascot-admonition-img" }
    This is the neutral style, used for general sidebars or introductions.

!!! mascot-welcome "Welcome!"
    ![Sage waving welcome](../img/mascot/welcome.png){ class="mascot-admonition-img" }
    This is the welcome style, used at chapter openings.

!!! mascot-thinking "Key Insight"
    ![Sage thinking](../img/mascot/thinking.png){ class="mascot-admonition-img" }
    This is the thinking style, used for key concepts.

!!! mascot-tip "Helpful Tip"
    ![Sage giving a tip](../img/mascot/tip.png){ class="mascot-admonition-img" }
    This is the tip style, used for hints and advice.

!!! mascot-warning "Watch Out!"
    ![Sage warning](../img/mascot/warning.png){ class="mascot-admonition-img" }
    This is the warning style, used for common mistakes.

!!! mascot-celebration "Well Done!"
    ![Sage celebrating](../img/mascot/celebration.png){ class="mascot-admonition-img" }
    This is the celebration style, used for achievements.

!!! mascot-encourage "Keep Going!"
    ![Sage encouraging](../img/mascot/encouraging.png){ class="mascot-admonition-img" }
    This is the encouraging style, used for difficult content.
